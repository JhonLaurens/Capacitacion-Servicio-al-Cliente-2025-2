# Capacitación Servicio al Cliente - Coltefinanciera 2025-2

## Implementación en Moodle

### 📋 Información General

- **Título**: Transformando Vidas a Través del Servicio
- **Versión**: 2.0
- **Formato**: SCORM 1.2
- **Compatibilidad**: Moodle 4.0+
- **Duración Estimada**: 45 minutos
- **Idioma**: Español (Colombia)

### 🎯 Objetivos de Aprendizaje

Al completar esta capacitación, los participantes podrán:

1. Aplicar la nueva tipología "PETICIONES" en la clasificación de casos
2. Ejecutar correctamente el procedimiento PR-M4-P2-01 de radicación
3. Implementar la metodología de análisis de causa raíz
4. Conocer el marco normativo vigente y la Circular 019 de 2024
5. Utilizar efectivamente las herramientas de supervisión y control

### 🔧 Instalación en Moodle

1. **Subir el Paquete SCORM**:

   - Ir a su curso en Moodle
   - Activar edición
   - Añadir una actividad → Paquete SCORM
   - Subir el archivo ZIP completo del paquete

2. **Configurar la Actividad**:

   - Aplicar la configuración recomendada arriba
   - Establecer restricciones de acceso si es necesario
   - Configurar fechas de disponibilidad

3. **Verificar Funcionamiento**:
   - Probar como estudiante
   - Verificar que el progreso se registre correctamente
   - Comprobar la navegación entre módulos

### 🛠️ Resolución de Problemas

#### Problemas Comunes:

**1. La actividad no carga correctamente**

- Verificar que el navegador tenga JavaScript habilitado
- Comprobar que el archivo ZIP no esté corrupto
- Revisar los logs de error de Moodle

**2. El progreso no se guarda**

- Verificar la configuración de SCORM en Moodle
- Comprobar que el usuario tenga permisos adecuados
- Revisar la configuración de auto-confirmar

**3. Problemas de navegación**

- Verificar que la tabla de contenidos esté habilitada
- Comprobar la configuración de ventana emergente
- Revisar restricciones de navegador
